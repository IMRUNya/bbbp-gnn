\section{Task and Dataset Inspection (Part A)}
\label{sec:data}
% Brief A (10): task/labels [2]; audit + canonical duplicates [3]; >=6 structures both classes [2];
% atom/bond distributions + one graph's shapes [3].

\textbf{Task.} Input: one molecule as a SMILES string, converted to a graph of atoms and bonds. Output: one
probability that it penetrates the blood--brain barrier. The unit of analysis is the \emph{molecule} --- one label
per graph, not per atom. The intended technical use is ranking candidate compounds so that slow laboratory assays go
to the most promising ones; it is not a clinical, diagnostic or safety tool. Label 1 means the compound was reported
as penetrating and 0 as non-penetrating, both curated research labels pooled from the literature
\cite{Martins, MoleculeNet} rather than measurements on a patient.

\textbf{Audit} (Table~\ref{tab:audit}). The PyTorch Geometric MoleculeNet loader \cite{PyG} returns each molecule as
a ready-made graph. The file holds 2050 rows but 2039 load: the 11 missing rows are exactly those whose SMILES RDKit
\cite{RDKit} cannot parse. No label is missing or non-finite and no graph is empty. At 76.5\,\% positive, always
answering ``penetrates'' already scores 0.765 accuracy, so accuracy alone says little here.

\textbf{Duplicates.} All 2039 raw SMILES are distinct, which hides them. Canonicalising every structure and comparing
those instead reveals 60 molecules occurring more than once over 124 rows. Fifty repeat with a consistent label and
were reduced to one copy; the other ten carry \emph{both} labels, so all records in those conflicting groups were
removed. They are ordinary drugs --- aspirin, levodopa, atropine (Table~\ref{tab:conflicts}) --- which suggests the
file pools sources that measured permeability differently. \textbf{1965 molecules remain}, and both splits were built
only after this cleaning.

\section{Molecular Graphs and Batching (Part B)}
\label{sec:graph}
% Brief B (12): feature meaning + encoding choice [3]; structure vs graph view [3];
% batch shapes explained [3]; integrity checks [3].

\textbf{Representation.} Each heavy atom is a node and each bond an edge. Hydrogens get no node of their own; the
hydrogen count is stored as an atom feature instead, which keeps the graphs small without losing information.
\texttt{x} holds 9 features per atom and \texttt{edge\_attr} 3 per bond, and \texttt{edge\_index} stores connectivity
in coordinate form with every bond listed twice, once per direction, so messages travel both ways.
Table~\ref{tab:features} gives the meaning of every column.

\textbf{Encoding: trainable embedding.} All twelve columns are category \emph{codes}, not quantities. A code is a
position in a list --- the formal-charge list starts at $-5$, so code 5 means charge 0, and hybridisation code 3
means SP2 --- so treating one as a number would claim SP2 is three times whatever code 1 stands for. Each column
therefore gets its own lookup table of trainable vectors, and an atom's nine vectors are summed into its starting
state:
\begin{equation}
    h_i^{(0)} = \sum_{c=1}^{9} W_c\!\left[X_{ic}\right] \in \mathbb{R}^{d}, \qquad d = 64,
    \label{eq:enc}
\end{equation}
with bonds encoded the same way. This equals one-hot encoding followed by a linear layer but is far narrower:
11\,328 atom and 1\,920 bond values against 177 and 30 mostly-zero one-hot columns, since only 13 of the 119 element
slots occur here.

\textbf{Two views} (Figure~\ref{fig:graphview}). The correspondence is exact and index-preserving: node $i$ is atom
$i$, so acetylsalicylic acid's 13 heavy atoms become 13 nodes and its 13 bonds become 13 undirected edges, which is
26 \texttt{edge\_index} entries. Orange marks the aromatic ring and blue the acetyl and carboxyl substituents; the
implicit hydrogens appear only as \texttt{num\_hs} on their atoms, never as nodes.

\textbf{Batching and checks.} A batch becomes one disconnected graph. For 32 molecules: \texttt{x} $(778,9)$ stacks
all atoms, \texttt{edge\_attr} $(1664,3)$ all directed edges, and \texttt{edge\_index} $(2,1664)$ is re-indexed by
the atoms already placed, so graph 1 starts at atom 20 --- graph 0's atom count --- and no edge crosses between
molecules. \texttt{batch} has length 778 with values $0\ldots31$, telling pooling which molecule each atom belongs
to, and \texttt{y} is $(32,1)$: one label per \emph{graph}. Iterating the dataset in batches of 64 recovered all
2039 graphs and 49\,068 atoms, every label finite, every graph non-empty and the label count equal to the graph
count in every batch, so no molecule is lost.

\section{Random and Scaffold Splits (Part C)}
\label{sec:split}
% Brief C (13): two 70:15:15 splits, acyclic rule [4]; coverage and disjointness [3];
% counts, positive rates, scaffold counts [3]; test untouched + why random is optimistic [3].

Both splits divide the 1965 cleaned molecules 70:15:15 with the single seed 42. The \textbf{random split} is
stratified, holding the positive proportion fixed. The \textbf{scaffold split} reduces every molecule to its
Bemis--Murcko scaffold \cite{Bemis} --- ring systems plus their linkers, side chains stripped --- then groups
molecules by scaffold and fills train, validation and test from the largest group down, never breaking a group.
Three cases need a documented rule:

\begin{itemize}
    \item \textbf{Invalid molecules} never reach this stage: the 11 unparsable SMILES and the 10 conflicting groups were removed in Part~\ref{sec:data}, so every molecule being split has a scaffold.
    \item \textbf{Acyclic molecules} have an empty scaffold and are all treated as one group, so they stay together rather than scattering molecules that have no ring system to generalise from.
    \item \textbf{Equal-sized groups} are shuffled with the same seed before sorting, which is not cosmetic. In blocks of 250 rows the positive share of the file runs 0.656, 0.524, 0.532, 0.428 and then exactly 1.000 for every block from row 1000 on --- the second half is sorted by label. Breaking ties by file position therefore drains the one-molecule scaffolds out of that all-positive tail and yields a single-class test set, on which ROC-AUC is undefined.
\end{itemize}

Both splits cover all 1965 molecules with pairwise-disjoint indices and no canonical SMILES shared across subsets,
and every subset's positive rate matches the full dataset to within half a percentage point
(Table~\ref{tab:splits}). They differ in one number: the random split puts \textbf{238 scaffolds on both sides} of
the divide, while the scaffold split puts none, its train, validation and test scaffold sets being fully disjoint.

Molecules sharing a scaffold are close relatives, often differing by one methyl group. A shared scaffold therefore
lets the model score well by recognising a measured near-twin instead of generalising, which is why a random split
gives an optimistic estimate. Real use is the opposite case --- a chemist asking about a new kind of molecule nobody
has measured --- and that is what the scaffold split imitates. Both test subsets were then set aside and scored
exactly once, in Part~\ref{sec:eval}.

\section{Fingerprint Baseline (Part D)}
\label{sec:base}
% Brief D (10): ECFP radius/length/meaning [3]; LR on training only, imbalance justified [3];
% validation-selected hyperparameter and threshold, frozen [2]; seed and settings [2].

\textbf{Fingerprint.} Morgan/ECFP4 from RDKit, \textbf{radius 2} and \textbf{2048 bits}: for each atom it collects
the neighbourhood within two bonds, hashes that fragment and sets the matching bit \cite{ECFP}. The vector records
\emph{which fragments a molecule contains} and nothing else --- not how they are arranged, and nothing learned from
the task --- which is what makes it a fair control. On these 1965 molecules 43 bits are set on average and only 4 of
the 2048 are never used, so the length is not wasted.

\textbf{Classifier.} Logistic regression \cite{sklearn} fitted on the training subset only, with each class weighted
by $w_k = n/2n_k$ \textbf{computed from the training subset alone}, so no validation or test information reaches the
weights. Weighting beats resampling here: undersampling would discard roughly 700 of the 1375 training molecules,
and oversampling duplicates structures without adding any.

\textbf{Selection, then freezing.} $C$ was picked from $\{0.01, 0.1, 1, 10, 100\}$ by validation ROC-AUC, which needs
no threshold; $C = 0.1$ won on both splits with 0.9024 and 0.8875, decaying steadily to 0.8863 and 0.8576 at
$C = 100$ --- sparse binary features need strong regularisation. The threshold was then set separately at the maximum
of Youden's index, sensitivity $+$ specificity $-1$ \cite{Youden}, rather than left at the arbitrary 0.5. It differs
between splits, 0.534 and 0.650, because the probabilities spread out differently once validation molecules share no
scaffold with training. Both were frozen before any test molecule was scored.

\textbf{Reproduction.} Seed 42 controls the split, the scaffold tie-break shuffle and the solver; the classifier is
logistic regression with $C = 0.1$, balanced class weights, the \texttt{lbfgs} solver and an iteration cap of 5000,
on Morgan fingerprints of radius 2 and 2048 bits.

\section{Graph Neural Network (Part E)}
\label{sec:gnn}
% Brief E (18): bond-aware architecture + parameter count [5]; training settings justified [5];
% loss/metric curves with under/over-fitting and instability identified [4]; three seeds, seed vs split [4].

\textbf{Architecture.} Atoms and bonds are encoded by Equation~\eqref{eq:enc} into $d = 64$, then three
\texttt{GINEConv} message-passing layers \cite{GIN, GINE} run. The layer is bond-aware because the bond encoding
enters the message itself,
\begin{equation}
    h_i^{(k+1)} = \mathrm{MLP}^{(k)}\Big( (1+\varepsilon^{(k)})\, h_i^{(k)} + \textstyle\sum_{j \in \mathcal{N}(i)} \mathrm{ReLU}\big(h_j^{(k)} + e_{ji}\big) \Big),
    \label{eq:gine}
\end{equation}
so the kind of bond matters as much as the neighbour across it, which is what separates an aromatic ring from a
saturated one of the same shape. Each layer wraps a $64 \to 128 \to 64$ perceptron with batch normalisation
\cite{BatchNorm}, ReLU and dropout 0.3, and after three rounds every atom knows its surroundings three bonds out.
Mean pooling gives one molecule vector, $h_G = |V|^{-1}\sum_{i \in V} h_i^{(K)}$, making the answer independent of
atom ordering but giving each atom a large say in a small molecule (Part~\ref{sec:err}); a two-layer head returns
one logit. \textbf{67\,588 trainable parameters.}

\textbf{Training.} Binary cross-entropy with logits, the positive class down-weighted by $n_-/n_+ \approx 0.31$ from
training counts --- the same balancing the baseline gets, so neither model has an easier objective. Adam \cite{Adam}
at learning rate $10^{-3}$, batch size 64, a budget of 150 epochs, early stopping after 25 epochs without an
improvement in validation ROC-AUC, and restoration of the best checkpoint. The budget was never reached: all six runs
stopped between 54 and 100 epochs. Three seeds, 0, 1 and 2, were run per split with the split seed fixed at 42, so
seed variation and split effect can be told apart. \textbf{All selection used validation data only.}

\begin{figure}[H]
    \centering
    \includegraphics[width=0.72\textwidth]{training-curves.png}
    \caption{All six runs. Left: training loss (solid) and validation loss (dashed). Right: validation ROC-AUC, dotted line marking the restored checkpoint. Top row random split, bottom row scaffold; colour denotes the seed.}
    \label{fig:curves}
\end{figure}

\textbf{What the curves show} (Figure~\ref{fig:curves}; per-run values in Appendix~\ref{app:seeds}).
\begin{itemize}
    \item \textbf{Overfitting}, clearly: training loss falls smoothly to 0.08--0.12 while validation loss bottoms out around epoch 5--10 and climbs back to 0.30--0.40 --- expected with 67\,588 parameters and 1375 training molecules.
    \item \textbf{No underfitting}: training loss is still falling when early stopping triggers.
    \item \textbf{Instability is noise, not drift}: the spikes in validation loss and the sawtooth in ROC-AUC come from validation subsets of only $\approx 295$ molecules, and their amplitude does not grow with training.
    \item \textbf{Validation ROC-AUC does not degrade while validation loss rises.} The network grows over-confident and cross-entropy punishes confident mistakes harshly, but the \emph{order} it puts molecules in keeps improving. Stopping on loss would have halted training near epoch 8 and discarded a better model --- hence checkpointing on ROC-AUC, and choosing the threshold on validation data.
\end{itemize}

\textbf{Seed versus split.} Across seeds, validation ROC-AUC varies by only $\pm 0.0022$ (random) and $\pm 0.0025$
(scaffold), while changing the split moves the mean by 0.0354 --- \textbf{seven times as much}, with no overlap
between the groups, since the worst random seed (0.9130) still beats the best scaffold seed (0.8822). The splitting
protocol causes the drop, not luck in initialisation. The seed changes the route instead: the best epoch lands
anywhere between 28 and 74 across runs of nearly equal final quality, which argues for checkpointing on a validation
score rather than a fixed epoch count.

\textbf{Baseline versus GNN.} The GNN wins both metrics that depend only on the \emph{order} of the predictions,
ROC-AUC and PR-AUC, on both splits. The baseline wins every metric needing a yes/no decision --- accuracy,
sensitivity and $F_1$ --- also on both splits. These are one fact from two sides: the network sorts molecules better
but cuts them in the wrong place. Its thresholds, $0.424 \pm 0.213$ and $0.748 \pm 0.248$, vary so much between seeds
that the three runs effectively use different cutoffs, while the heavily regularised linear model produces
well-behaved probabilities and converts a lower ROC-AUC into a higher $F_1$.

\textbf{What the evidence supports} is a weak ranking advantage, no more. On the scaffold split the gap is 0.009
ROC-AUC against a seed spread of 0.025, nearly three times larger, so \emph{the two models cannot be distinguished
there}; on the random split the gap of 0.020 is about 2.5 times the seed spread, which is suggestive but rests on
three runs and one split seed. A fingerprint matching a graph network on BBBP is a repeatedly reported result
\cite{Chemprop}: with 1375 training molecules there is little for 67\,588 parameters to find beyond which fragments
are present. The assumption that a GNN must win is not supported here.

\textbf{Random versus scaffold.} Both models lose ground when scaffolds are held apart and the GNN loses slightly
more, consistent with it partly recognising familiar scaffolds. The scaffold numbers are the ones to quote for a
genuinely new molecule; the random ones are an optimistic ceiling inflated by those 238 shared scaffolds. Neither set
proves biological usefulness --- see Part~\ref{sec:err}.

\textbf{Does similarity explain the errors?} Partly. The median nearest-neighbour similarity over the whole scaffold
test subset is only \textbf{0.400}, far below the 0.7 rule of thumb for calling two molecules similar, so the model
is generally asked about molecules unlike anything it was trained on, and all four errors sit at or below that
median. Three of the four simply \emph{copied the neighbour's label}. Both false positives latched onto a shared
fragment: one holds two glutarimide groups on a polar linker while its neighbour is a single glutarimide labelled as
penetrating --- yet doubling the group is exactly what makes a molecule too large and too polar to pass. The second
false negative is the mirror image, a small chromone acid matched to a double-sized relative labelled as
non-penetrating. Similarity does \emph{not} explain the fourth: a cyclic acetal with true label 1 scored 0.005
although its neighbour is labelled 1 and predicted 1.000. Size explains that one --- 7 heavy atoms against the
typical 23, three of them oxygens, and mean pooling leaves almost nothing to dilute that oxygen signal. Low
similarity also fails to make the model cautious: the macrocycle, 0.220 from anything in training, still got 0.989.
The probability therefore carries no warning about whether a molecule is one the model may judge, and a
nearest-neighbour check beside the model would have flagged all four cases.

\textbf{Limitations.}
\begin{itemize}
    \item \textbf{Label uncertainty.} The labels are not ground truth: ten molecules in this one file carry both at once, every row from 1000 onwards is positive, and the underlying property is a continuous permeability measured by differing protocols and then compressed into a yes/no.
    \item \textbf{Dataset size.} 1965 molecules, 1375 of them for training. With 296 scaffold-test molecules the confidence interval on ROC-AUC is roughly $\pm 0.04$, wider than the 0.009 gap between the two models --- which is why that gap cannot be called a win.
    \item \textbf{No external experimental validation.} Everything comes from one curated file. No molecule was tested in a laboratory, and no second dataset, assay or site was used to check whether the model transfers.
    \item \textbf{No abstention.} The model answers confidently where it has almost no data, as the errors above show.
\end{itemize}

\textbf{No causality, no clinical suitability.} The model has learned which fragments tend to accompany which
label. It knows nothing about diffusion, transport proteins, efflux pumps or dose, and cannot tell a molecule that
never enters the brain from one that enters and is pumped straight back out. A high score means only that a molecule
\emph{resembles the compounds this file labelled as penetrating}: it identifies no cause of permeability and gives
no indication that a compound is safe, effective or ready for development.

\section{Reproducibility}
\label{app:repro}

Every number in this report comes from one top-to-bottom execution of the accompanying notebook, which takes about
2.5 minutes on CPU. The split seed is 42 and controls stratification, scaffold tie-breaking and the baseline solver;
the network seeds are 0, 1 and 2 and control initialisation, dropout masks and batch order. Training is deterministic
on CPU at these seeds, so a re-run reproduces the reported values exactly. The repository linked on page~1 holds the
executed notebook with all outputs visible, a \texttt{README.md} giving the run order and environment notes, a
\texttt{requirements.txt} pinning versions. The downloaded MoleculeNet directory is git-ignored, as required.
