\begin{abstract}

This report predicts whether a molecule crosses the blood--brain barrier, using the BBBP dataset from MoleculeNet. Two models are compared: a graph neural network that learns its own description of each molecule, and a logistic regression on fixed ECFP4 fingerprints. Each is trained twice, once on a random split of the data and once on a scaffold split that keeps molecules with the same ring system in the same subset. On the scaffold split the network reached a test ROC-AUC of $0.885 \pm 0.025$ against the fingerprint model's $0.876$; on the random split, $0.912 \pm 0.008$ against $0.892$. The fingerprint model was better on accuracy and $F_1$, because the network orders molecules well but its probabilities are badly calibrated. How the data was split mattered about seven times more than which random seed was used, and on the scaffold split the two models cannot be told apart. The sections below follow Parts A to G of the assignment.

\end{abstract}
